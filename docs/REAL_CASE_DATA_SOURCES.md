## Data integrity rules

1. Keep the original publisher name and URL with every record.
2. Record when a source was published and when CASEZERO last checked the status.
3. Distinguish a family's allegation, a police statement, a court observation, and a proven finding.
4. Never auto-publish a GDELT/news-feed result as a verified case. GDELT is a discovery feed; a person must review the original source before a case enters the public archive.
5. Avoid exposing private contact details, national identity numbers, graphic images, or personal information that is not necessary to understand the public record.
6. Recheck statuses before describing a case as currently open, missing, or unidentified.
